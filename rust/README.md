# Rust track

Rust 是本书两种实现路线之一。当前已提供[阅读 0 · Rust 版](../docs/readings/00-rust.md)与独立预备练习；正式章节的 Harness 实现仍待建设，目录中的四个设计对照主题与附录仍为规划。

- `src/`：未来的 Rust 对照实现
- `tests/`：未来与重叠合同对应的验收用例
- `examples/reading-00/`：独立 Cargo 项目，练习本地响应解析、错误处理与异步调用；运行和验证命令见材料正文

Cargo manifest 与锁文件只位于预备练习目录中，`rust/` 根目录尚未建立正式工程。预备练习不请求模型服务，也不代表正式 Harness 的能力已实现。
