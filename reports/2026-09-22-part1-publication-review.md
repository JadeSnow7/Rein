# 第一部分文字发布审查

审查日期：2026-09-22。范围以当前 `book/chapters.json` 的第一部分为准：新版 00–03 章、01 Rust 对照页、阶段汇总 1，共六篇。原数字页面保留为历史稿件，未纳入本轮改写。

## 结论与范围

本轮把第一部分整理为可审阅的发布候选稿。审查重点是教学顺序、文字表达、事实与当前源码的一致性，以及读者能否找到正确的命令、输入和判断条件。主线程与独立审查者已复核六篇稿件，已识别的文字与示例问题均已修订；结论限于本轮六篇，不代表整库或全书验收。

当前产品运行时与教材进度分别判断。R1a 记录中的离线只读增量通过，不意味着新版章节已验收；`book/chapters.json` 中的草稿状态、`actual: false`、空快照和未试用提示词保持原样。本轮没有使用真实模型，也没有完成读者试读、章节快照封存或发布。

## 主要问题与修订

| 原问题 | 对读者的影响 | 本轮处理 |
| --- | --- | --- |
| Rust 主流程切换旧本地 `ch01-helloworld` 标签 | 新克隆读者可能拿不到标签，且切换后的树不含新版书籍索引 | 统一使用当前工作副本，旧标签保留历史语义 |
| 新版正文沿用旧 02、04、05 路径与编号 | 进入旧草稿，或把新版迁移章误当循环章 | 主线改用稳定 slug；04 为适配器、05 为迁移、06 为循环 |
| 阶段汇总要求尚未存在的结束快照 | 读者无法找到正式复查起点 | 给出当前工作副本可执行的复查步骤；正式快照验收明确待补 |
| 00、02 接近提纲，任务条件不足 | 能记住术语，却难以判断一次回答对不对 | 补完整场景、角色分工、具体预期、正反例与四类固定任务 |
| 首章残留图示占位、碎片化口语与不完整练习 | 操作与概念解释断开 | 采用作者后续手工稿约定，使用完整段落和直接操作标题 |
| 把兼容接口误当成参数行为相同 | 使用第一章配置进入工具章可能失败 | 核对官方参数限制，在第三章保留必要的端点条件处理 |
| 工具失败与 CLI 正常退出混为一谈 | 把说明“文件不存在”的成功通信当作任务成功 | 明确检查工具结果、回答和退出码各自能证明什么 |
| 操作权限、模型回答与实际动作混淆 | 误认为写在提示词中的约束已经由程序强制保证 | 在 00、02、03 分别解释角色、任务要求和执行边界 |
