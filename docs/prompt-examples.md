# 提示词示例使用说明

本书第一至五部分由人确定设计和验收条件，AI 编程助手按设计编写代码（见[全书分工](./chapters/minimal-agent.md#division)）。因此从第 04 章起，每章**正式正文末尾**附一份与本章任务对应的提示词：它由本章的设计卡、验收样本和约束组装而成，供你交给 Claude Code、Codex 等代码助手使用。01–03 不附提示词，也不要求使用代码助手。

## 来源标注

每条提示词都标明来源，不用笼统的免责声明代替：

| 标注 | 含义 | 必须附带 |
| --- | --- | --- |
| 作者实际使用 | 开发配套实现时真实交给 AI 的设计或提示词 | 开发记录链接 |
| 据设计反推 | 从现有设计卡和实现倒推，供读者参考 | 反推依据；注明未经运行 |
| 已试用 | 反推或改写后又实际运行过一次 | 起始快照、代码助手与模型、实际 diff、验收结果 |

单次试用只说明那一次的结果，不保证换模型、换版本或换工具后仍然相同。

## 怎样使用

大模型输出具有不确定性，相同提示词也可能得到不同结果。使用前先确认章节起点和允许修改的范围；运行后检查实际 diff，并用本章的验收样本判断结果，保留失败记录。代码助手回复“已完成”不等于验收通过。

Rein 自身的系统提示、任务消息和工具描述是程序的一部分，在正文中解释，与这里给代码助手的提示词用途不同。提示词工程、防御性编程和 AI 常见失误的处理，会在后续相应章节深入讨论；04 只给出最基本的用法。
