```sh

CARGO_TARGET_DIR="$REIN_LESSON_TMP/rein-v2-cargo-target" cargo test --locked --manifest-path rust/Cargo.toml --test maintenance_profile --test maintenance_session
```

测试会创建独立临时工作区，覆盖批准、拒绝、基线变化、无须修改、失败后的修复以及修复上限。读者还要检查每次失败的原始验证输出是否保留，不能只统计最后成功的次数。
