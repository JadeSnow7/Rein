# 关于本书

## 书的目标

《Rein：从零手写一个 Agent Harness》面向已经具备基础编程能力、希望系统学习 Agent 工程并准备求职的读者。它不从框架 API 清单开始，而是从一次模型调用开始，逐步回答：模型如何获得环境信息？工具如何受到约束？系统如何判断任务真的完成？

全书围绕名为 **Rein** 的工作区助手演进：回答问题 → 读取文件 → 连续行动 → 提出修改 → 验证结果 → 规划与协作，并提供 TypeScript 与 Rust 两种实现路线。当前已完成的第 01 章正文使用 TypeScript。

## 如何阅读

建议沿主线阅读。每章都会把一个问题变成可运行的增量，再用成功与失败用例检查它。

主线代码在 `ts/src/` 只保留一份随正文演进的版本。章节快照 tag 在对应章节完成并核验后建立，取某一章结束时的状态直接检出即可。当前已建立初版快照 `ch01`，其余章节的 tag 随正文推进逐个建立。第 01 章后续修订保留原快照，正文末尾说明修订内容与快照的差别。

## 两条 track

仓库以 `ts/` 与 `rust/` 分别承载两种语言的实现。阅读 0 已提供同一任务的两个独立版本；选定一种语言即可开始，也可以对照代码理解语言差异。

当前 TypeScript 第 01 章已有调用代码与测试，Rust 已有阅读 0 预备练习，正式章节的 Rust Harness 与共享合同仍待建设。目录中的四个 Rust 设计对照主题与附录保留；后续章节的双语言实现范围与完成状态随交付更新，不将预备练习视为正式章节实现。

正式书版发布时将固定一个 tag（例如 `book-v1`），并对合同显式版本化。模型 API 的变化与适配将记录在 `MIGRATIONS.md`；当前尚未发布书版 tag，也没有迁移记录。
