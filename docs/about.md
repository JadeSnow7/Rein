# 关于本书

## 书的目标

《Rein：从零手写一个 Agent Harness》面向已经具备基础编程能力、希望系统学习 Agent 工程并准备求职的读者。它不从框架 API 清单开始，而是从一次模型调用开始，逐步回答：模型如何获得环境信息？工具如何受到约束？系统如何判断任务真的完成？

全书使用 TypeScript 作为叙事主线，围绕名为 **Rein** 的工作区助手演进：回答问题 → 读取文件 → 连续行动 → 提出修改 → 验证结果 → 规划与协作。

## 如何阅读

建议沿主线阅读并保留每个阶段的代码快照。每章都会把一个问题变成可运行的增量，再用成功与失败用例检查它。标记“可独立阅读”的章节会提供自己的背景、最小接口和运行示例，适合单独取用。

站点上的免费标记表示公开发布计划；GitHub Pages 是公开站点，不提供付费内容的访问控制。未来如有知识付费内容，将使用独立的交付与权限系统。

## 两条 track

计划建立 `ts/` 与 `rust/` 两条实现路线，在重叠能力范围内共享合同与验收用例。正文只跟随 TypeScript；Rust 在四个主题中作为短篇对照，并在附录展开。当前仓库仅包含书籍站点，两条实现路线尚未建立。

正式书版发布时将固定一个 tag（例如 `book-v1`），并对合同显式版本化。模型 API 的变化与适配将记录在 `MIGRATIONS.md`；当前尚未发布书版 tag 或建立迁移记录。
