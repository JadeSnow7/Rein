# 全书目录

这是一份持续更新的规划目录。标注“永久免费”的内容会保持免费开放；标注“限时免费”的内容后续可能转为收费；“可独立阅读”表示完成后可单独取用；“Rust 对照”表示计划配套的 Rust 实现。以下全部章节、实现与发布节点均为规划，尚未交付。

学习目标：建立直觉，尽早跑通“模型调用工具并根据结果回答”的过程。

## 第三阶段：让 Agent 做对，并知道自己是否做对

学习目标：解决真实使用时最容易暴露的上下文、反馈和执行边界问题。

### 07 上下文管理（限时免费） {#ch07}

[进入章节页面 →](./chapters/07.md)

从历史过长的失败开始，组织规则、目标、工具结果和运行历史，建立可观察的上下文预算。

### 08 上下文管理方法：四种做法的横向对比（可独立阅读·限时免费） {#ch08}

[进入章节页面 →](./chapters/08.md)

实现按需读取、窗口裁剪、摘要和检索，用同一组任务测量同一批指标，给出有条件的结论。

### 09 验收条件与验证器（可独立阅读·限时免费） {#ch09}

[进入章节页面 →](./chapters/09.md)

把任务成功标准写成机器可判定的形式，讨论测试、类型检查、运行时断言和声明式断言各自能证明什么。

### 10 失败反馈与循环工程（限时免费） {#ch10}

[进入章节页面 →](./chapters/10.md)

把失败信息组织成模型可用的形式，区分可自动修复、需要重新规划和必须交还人类的失败。**Rust 对照 2：工具执行中的进程、资源与取消。**

### 11 防御性编程——AI 的矛与盾（永久免费·可独立阅读） {#ch11}

[进入章节页面 →](./chapters/11.md)

从具体失败案例学习输入校验、提示注入防御、敏感信息处理、重复执行与结果未知，并配套防御测试。

### 12 权限管理：把修改变成可审查的差异（可独立阅读·限时免费） {#ch12}

[进入章节页面 →](./chapters/12.md)

区分只读与修改，建立允许、拒绝和批准流程；每次修改先以人类可读差异呈现，检查后才应用。

### 阶段性汇总 2　一个能够审查修改的编码助手（限时免费） {#chsum3}

[进入阶段汇总 →](./milestones/03.md)

完成“理解任务—读取文件—提出修改—人工批准—执行验证”，展示工具过程、差异和验证结果。**发布节点：Rein v0.3**

## 第四阶段：让 Agent 承担更完整的任务

学习目标：在单个 Agent 可用的基础上，引入计划、协作和外部能力。

### 13 计划与任务审查（限时免费） {#ch13}

[进入章节页面 →](./chapters/13.md)

### 14 多智能体协作（可独立阅读·限时免费） {#ch14}
