# 第五部分：实际应用

**21–24｜规划中。** 将有界 Harness 接入 Web Studio 轻量 IDE，让任务、当前编辑器内容、候选差异、批准和验证在真实交互中可见。网页或桌面界面显示成功，不代替运行记录。

## 21 设计 IDE 与 Harness 的连接方式 {#ch21}

定义 UI、Rust core 和工作区之间的请求、事件、取消与恢复边界，标出每种状态的所有者。

## 22 把编辑器上下文交给 Agent {#ch22}

区分磁盘文件与未保存缓冲区，限定发送的选区、文件和项目上下文，避免用旧内容生成候选。

## 23 完成一次真实开发任务 {#ch23}

沿“提交任务→观察工具→审查 diff→批准→验证”完成一个有界纵切，保留失败、放弃与重试路径。

## 24 评测、打包与项目复盘 {#ch24}

核对可安装产物、交互与运行证据，分开报告演示成功、产品验收和仍未验证的能力。
