# 第四部分：Agent 扩展

**16–20｜规划中。** 这些能力各有前置条件，可按需要加入已通过第三部分检查的单 Agent Harness。扩展不能自行扩大原有工具权限、预算或交付范围。

## 16 计划模式：先组织任务，再执行 {#ch16}

把任务拆为有依赖和验收条件的步骤，审查计划之后再让已授权的步骤执行；计划文本本身不等于执行证据。

## 17 Skill：加载可复用的工作方法 {#ch17}

定义何时加载方法、怎样限制其范围，以及如何区分参考指令与当前用户任务。

## 18 扩展接口与执行 Hooks {#ch18}

让外部宿主通过版本化、可校验的接口接收调用；Hooks 在明确执行节点介入，记录输入、决定与失败。

## 19 接入 MCP 工具 {#ch19}

在已有工具适配边界接入 MCP，校验能力发现、工具参数、权限与结果；外部工具仍受 Harness 的任务范围约束。

## 20 多智能体与受限委派 {#ch20}

给被委派者限定任务、预算和可访问资源；汇总时检查证据与冲突，不能把子任务回复直接当作总任务完成。

本部分结束后进入[第四阶段成果](../milestones/part-04.md)；[实际应用](./part-05.md)只要求第三部分的基础能力，不要求先完成全部扩展。
