# Contracts

## 跨项目运行接口候选

[RuntimePort 0.1](runtime-port-v0.1.md) 是 Rein 与 Veriflow 之间的语言中立契约候选，规定单次执行的输入、状态、事件、取消、恢复、权限和原始产物语义。它是**待实现的设计**，不是现有 CLI、SDK 或服务接口；与教学合同分开版本化。

该候选沿用未合并 PR #3 的运行时概念，并列出 DTO 映射和缺口，不修改或另行生成它的四份 schema。后续正式 runtime 类型采用一个权威定义源，再生成 schema 和消费者类型；Veriflow 仅引用该版本，不复制 Rein 的会话状态机。

## 教学共享合同

`ts/` 与 `rust/` 在重叠能力范围内共享的合同：消息、工具调用、工具结果的形状，以及兼容边界与版本。

**main 的教学共享合同当前尚未定义。** 首个版本由原第 04 章从已有调用代码中推导——读者需要先经历"两家响应对不上"的具体麻烦，抽象才有意义，因此不提前定稿。这条教学安排不等于跨项目接口已经实现，也不阻止记录独立的运行接口候选。

已经冻结的是 [fixtures/](../fixtures/README.md) 的目录布局与命名，它属于合同的一部分：两条 track 读同一份验收数据。

正式书版发布时固定 tag 并对合同显式版本化，变化记录在 [MIGRATIONS.md](../MIGRATIONS.md)。
